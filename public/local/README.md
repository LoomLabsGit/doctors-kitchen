# Local-only assets

DK's own photos and audio used by the prototype live here. Everything in this folder except this README is git-ignored, so it stays on the machine it was added to and never reaches GitHub.

Without these files the prototype still works: photos fall back to the gradient placeholders and cook-along audio shows "Audio isn't available on this device".

## One-Pan Harissa Chicken and Chickpea Pasta (`harissa/`)
- `hero.webp`: the finished dish (recipe photo on cards, carousels and Recipe detail)
- `step1.mp3` to `step11.mp3`: Dr Rupy reading each cook-along step
- `step1.webp`, `step3.webp`, `step5.webp`, `step6.webp`, `step7.webp`, `step9.webp`, `step10.webp`, `step11.webp`: step photos (steps 2, 4 and 8 are prep-only and show a placeholder)
